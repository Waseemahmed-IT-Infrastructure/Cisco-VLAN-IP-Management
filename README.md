
# Cisco VLAN and IP Management

## Overview

This project covers VLAN planning, IP addressing and switch port management in Cisco networks.

I have worked with VLANs and IP configurations during network deployment and troubleshooting tasks.

## VLAN Management

VLANs help separate different devices and network traffic.

For example:
- VLAN 10 - User devices
- VLAN 20 - Servers
- VLAN 30 - Printers
- VLAN 99 - Network management

These are example VLANs, not production network details.

## IP Addressing

IP addresses are used to identify and communicate with devices on a network.

My work includes assigning management IP addresses, checking subnet masks and verifying gateway settings.

## Switch Port Management

Access ports connect devices to a specific VLAN.

Trunk ports allow multiple VLANs to pass between switches and other network devices.

## Common Cisco Commands

| Command | Purpose |
|---|---|
| `show vlan brief` | Check VLANs and port assignments |
| `show interfaces status` | Check port status |
| `show interfaces trunk` | Check trunk connections |
| `show ip interface brief` | Check interface IP addresses |
| `show running-config` | Review switch settings |

## Troubleshooting

When checking VLAN or IP connectivity issues, I usually look at:

- Correct VLAN assignment
- Interface status
- IP address and subnet mask
- Default gateway
- Trunk configuration
